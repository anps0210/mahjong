# 雀 ROOM - 온라인 마작 MVP

## 실행
1. Node.js 18 이상 설치
2. 이 폴더에서 `npm install`
3. `npm start`
4. 브라우저에서 `http://localhost:3000` 접속

다른 사람과 실제로 접속하려면 이 프로젝트를 Node.js 서버를 지원하는 호스팅(Render, Railway 등)에 배포해야 합니다. 정적 웹호스팅만으로는 Socket.IO 실시간 방 기능이 작동하지 않습니다.

## Render 배포

저장소의 `render.yaml`은 Node.js 24 기반 무료 웹 서비스 설정입니다. Render 계정을 연결한 뒤 Blueprint로 이 저장소를 선택하면 `npm ci --omit=dev`로 설치하고 `npm start`로 실행합니다. 포트는 Render가 제공하는 `PORT`를 사용합니다. 생성 이후 `main`에 새 커밋이 올라오면 자동 배포됩니다.

[Render에서 배포 설정 열기](https://render.com/deploy?repo=https://github.com/anps0210/mahjong)

- 상태가 메모리에만 있으므로 서버 인스턴스는 하나로 운영해야 합니다.
- 무료 서비스는 유휴 상태에서 정지될 수 있으며 다시 접속할 때 기동 시간이 필요합니다. 정지·재시작·재배포 시 기존 방은 사라집니다.
- 배포 후 새 방에서 4명이 참가하고 게임 시작 → 새로고침 → 같은 손패/좌석 복구 → 다음 타패가 되는지 확인합니다. 한 명의 연결이 끊겼을 때 일시 정지되고 복귀 후 재개되는지도 확인합니다.
- 정식 장시간 대국 운영 전에는 영속 상태 저장과 서버 재시작 복구가 필요합니다.

## 현재 구현
- 5자리 방 코드 생성 및 참가
- 최대 4명 대기실, 방장 시작 권한
- Socket.IO 실시간 참가자/턴 동기화
- 136장 패산 생성 및 13장 배분
- 현재 차례 플레이어의 패 버리기 및 다음 플레이어 드로우
- 재접속 토큰으로 같은 탭의 새로고침/통신 재연결 시 기존 좌석·손패·턴·전체 버림패 복구
- 참가자 연결 끊김 시 대국 일시 정지, 전원 복귀 시 재개
- 4명 모두 연결된 경우에만 시작, 중복 참가 차단, 연결된 참가자에게 방장 승계
- 패산 소진 시 대기실 복귀 및 방장의 다음 게임 시작

## 재접속 정책
- 서버가 발급한 비공개 토큰을 브라우저의 `sessionStorage`에 저장합니다. 같은 탭의 새로고침과 일시적인 연결 끊김은 자동 복구됩니다.
- 토큰으로 복구하면 이전 소켓의 접근을 종료합니다. 닉네임이나 방 코드만으로 기존 손패를 가져올 수 없습니다.
- 대기실의 연결 끊긴 좌석은 5분간 보존한 뒤 해제합니다. 방장 승계는 좌석 순서를 바꾸지 않습니다.
- 대국 중에는 이탈자의 좌석을 유지하고 전원 복귀까지 진행을 멈춥니다. 최소 한 명이 연결되어 있으면 대국 상태를 유지하며, 전원이 끊기면 마지막 연결 종료부터 5분 뒤 방을 삭제합니다.
- 새 탭·다른 기기·탭 종료 후에는 토큰을 사용할 수 없을 수 있습니다. 브라우저 저장소가 차단되면 새로고침 복구가 보장되지 않습니다.
- 상태는 서버 메모리에만 저장합니다. 서버 재시작/재배포 후 복구와 여러 서버 인스턴스 간 공유는 지원하지 않습니다. 영구 이탈자의 대체 플레이·기권 처리도 아직 없습니다.

## 테스트
`npm install` 후 `npm test`를 실행합니다. 실제 Socket.IO 연결과 jsdom에서 실행하는 클라이언트 코드로 재접속, 토큰 검증, 중복 접속 교체, 시작 조건, 방장 승계, 만료, 유국 후 재시작을 검증합니다.

## 아직 구현되지 않은 기능
암깡/가깡, 화료/후리텐 판정, 점수 계산, 동풍전/반장전, 유국 정산·도중유국, 관전은 아직 없습니다. 이 버전은 온라인 방과 기본 턴 진행을 확인하는 프로토타입입니다.

## 혼자 연습하기
방을 만든 뒤 **빈자리에 연습봇 추가 → 게임 시작**을 누르면 혼자서도 플레이할 수 있습니다. 2~3명이 모인 방에서도 남은 자리만 봇으로 채웁니다. 방장은 대기실에서 봇을 뺄 수 있습니다.

봇은 자신의 손패와 공개된 버림패만 사용해 일반형·치또이츠·국사무쌍의 샹텐 수를 줄이고 유효패 수를 늘리는 방향으로 타패합니다. 약 0.9초 간격으로 행동하며 사람이 연결을 잃으면 멈추고 복귀 후 재개합니다. 화료·점수 정산 기능은 아직 게임 자체에 없으므로 현재 봇은 패 만들기와 화면 조작 연습용입니다.

## 치·퐁·대명깡
다른 사람이 버린 패를 울 수 있으면 해당 버림패가 빛나고 치/퐁/깡 및 스킵 버튼이 표시됩니다. 치는 바로 앞 순서의 플레이어에게서만 가능하며, 여러 조합이 있으면 손패 조합을 보고 선택합니다. 모든 대상자의 선택이 끝날 때까지 다음 쯔모를 멈추고 퐁·깡을 치보다 우선합니다. 같은 우선순위는 버린 사람 다음 순서부터 처리합니다.

부로는 공개 영역에 표시하며 가져간 버림패는 흐리게 표시합니다. 치·퐁 직후 같은 패/스지 바꿔치기(쿠이카에)를 막습니다. 대명깡은 왕패에서 영상패를 받고 생패산 끝의 한 장을 왕패로 옮깁니다. 한 국 최대 4회까지만 깡할 수 있습니다. 선택 중 연결이 끊기면 일시 정지하고 복귀 시 선택 화면을 복구합니다.

이번 기능은 버림패로 하는 치·퐁·대명깡입니다. 암깡·가깡·깡도라·사깡산료 및 화료/역 판정은 후속 구현 대상입니다. 연습봇은 현재 멘젠 타패 전략을 유지하며 부로 기회에는 자동 스킵합니다.

## 리치와 샹텐 도움말
- 자기 차례에 멘젠 텐파이, 1,000점 이상, 생패산 4장 이상이면 **리치 · 1,000점** 버튼이 켜집니다. 누르면 리치 가능한 타패만 강조하며, 선택 취소도 가능합니다. 강조된 패를 버리는 순간 선언과 1,000점 공탁이 함께 확정됩니다.
- 리치 후에는 쯔모기리만 허용하고 부로 선택은 제공하지 않습니다. 선언패에는 리치 표식을 붙이고 좌석에 리치 상태·점수를 표시합니다. 봇도 같은 조건으로 리치합니다.
- 시작 점수는 25,000점입니다. 유국 후 다음 게임에서도 점수와 공탁금을 유지하며 리치 상태는 초기화합니다. 현재 화료/점수 정산이 없으므로 공탁금 수령, 리치 역·일발·더블리치·우라도라 계산은 아직 하지 않습니다.
- **샹텐 수 표시** 체크박스로 자신의 손패 도움말을 켜고 끌 수 있습니다. 설정은 같은 브라우저의 localStorage에 저장합니다. 일반형은 부로 수를 포함해 계산하고, 멘젠이면 치또이츠·국사무쌍도 비교합니다. 0은 텐파이, -1은 완성형으로 표시합니다. 이 값은 패 형태의 거리이며 역 유무·후리텐·실제 남은 유효패를 보장하지 않습니다. 상대 손패의 샹텐은 전송하지 않습니다.

## 모바일 가로 화면과 패 선택
- 모바일 가로 화면 높이에 맞춰 테이블·점수·손패를 함께 배치합니다. 세로에서는 회전 안내를 표시하며, 지원 브라우저에서 전체화면 버튼을 사용할 수 있습니다.
- 손패는 첫 터치로 선택하고 선택한 같은 패를 다시 눌러 버립니다. 선택패는 위로 올라가며 같은 종류의 버림패가 진하게 표시됩니다. 다른 장을 누르면 선택만 이동합니다.
- 리치 선언패도 두 번 눌러 확정합니다. 정렬 변경, 손패 갱신, 연결 종료 시 선택을 초기화해 의도하지 않은 타패를 방지합니다.
