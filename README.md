# 雀 ROOM - 온라인 마작 MVP

## 실행
1. Node.js 18 이상 설치
2. 이 폴더에서 `npm install`
3. `npm start`
4. 브라우저에서 `http://localhost:3000` 접속

다른 사람과 실제로 접속하려면 이 프로젝트를 Node.js 서버를 지원하는 호스팅(Render, Railway 등)에 배포해야 합니다. 정적 웹호스팅만으로는 Socket.IO 실시간 방 기능이 작동하지 않습니다.

## 현재 구현
- 5자리 방 코드 생성 및 참가
- 최대 4명 대기실, 방장 시작 권한
- Socket.IO 실시간 참가자/턴 동기화
- 136장 패산 생성 및 13장 배분
- 현재 차례 플레이어의 패 버리기 및 다음 플레이어 드로우

## 아직 구현되지 않은 기능
치/퐁/깡, 리치, 화료/후리텐 판정, 점수 계산, 동풍전/반장전, 자동 유국 판정, 관전 및 재접속 복구는 아직 없습니다. 이 버전은 온라인 방과 기본 턴 진행을 확인하는 프로토타입입니다.
